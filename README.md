## Проблема
Ручная обработка заявок занимает 2-3 часа, теряются лиды.

## Решение
4 агента обрабатывают заявку за 30 секунд:
1. **Classifier** — определяет тип услуги, срочность, регион, классы опасности.
2. **Responder** — генерирует персонализированный ответ клиенту.
3. **Documenter** — создает черновик коммерческого предложения (КП).
4. **Publisher** — сохраняет результаты в файлы.

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python main.py "Нужна пропарка 3 цистерн"          # mock-режим (по умолчанию)
python main.py --real "Нужна пропарка 3 цистерн"   # реальный API (нужен ключ в .env)
python main.py --demo                               # прогон всех 3 примеров in mock
python main.py --file request.txt                   # from file in mock
```

## Технологии
Python 3.10+, Claude API (опционально), argparse, logging.

**Примечание:** В mock-режиме классификатор распознает 8 ключевых городов (Норильск, Хабаровск, Якутск, Москва, СПб, Новосибирск, Красноярск, Владивосток). Для реального распознавания любых регионов используется Claude API.
